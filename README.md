# CNC 木頭顏料罐架產生器

在瀏覽器中參數化生成可**水平／垂直延伸**的壁掛式顏料罐木架，3D 預覽並匯出 CNC 切割檔（DXF / SVG）。

## 使用

```bash
npm start          # 開啟 http://localhost:8080
npm test           # 幾何與零件生成測試
```

（純靜態網頁，three.js 由 CDN 載入，任何靜態伺服器皆可。）

### GitHub Pages

`.github/workflows/pages.yml` 會在每次推送時先跑測試，再把網頁部署到 GitHub Pages。
第一次使用需到 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

## 功能

- **參數三層、全部連動**：
  - **基本**（7 項）：木頭厚度、組裝公差、顏料罐直徑、顏料罐高度、預計放幾種（每種一列）、每種放幾罐、罐頂到上層距離（最小值 = 固定孔板高度 + 8mm，罐子提得起、好拿；只能往上調，孔板抬高時下限跟著抬高）。
  - **加工與五金**（4 個選單）：銑刀、板材尺寸、掛牆螺絲、模組鎖點螺栓——掛孔尺寸、鎖點孔徑、排版間距等自動由此推算。
  - **進階**（預設收合、全部自動）：罐間距、罐孔餘隙、固定孔板高度、邊距、每模組欄／列數…會隨基本參數連動。輸入數值即可覆寫；若與其他參數衝突（例如孔板低於層板、模組比板材大），會自動調整並在欄位下方說明原因；清空或按「改回自動」即恢復連動。
- **自動模組化**：單一模組自動控制在約 600mm 內且一定放得進板材；罐數或種類超過時自動水平延伸／垂直堆疊。所有模組都切出延伸槽，日後可再擴充。
- **接縫不留白**：模組沒有自己的頂板，最上一列的頭頂空間直接接到上一個模組的底層板，上下接縫處仍是完整罐位、列距一致；最上面另外疊一組「頂蓋」（頂板＋兩片短側板，用同樣的卡扣與連接板接上），頂端名牌就立在頂蓋上。罐子與側板之間自動留出放連接板與卡扣腳的距離。
- **牆面掛點**：直接拖拉橘色球移動（可設定吸附間距）；雙擊背板新增、Delete 刪除，也可在側欄輸入精確座標。掛點會在所在模組的背板切出鑰匙孔；若落在側板、榫槽或背板外則標紅、不切孔。
- **精簡版面**：側欄頂端一行總尺寸與模組摘要，下分「設計／名牌／掛點／材料」四個分頁；視角、罐子、尺寸線、爆炸圖放在畫面左下的工具列；左上提示列隨選取狀態說明可做的操作；游標移到零件上直接顯示名稱與尺寸。掛點分頁列出每個掛點到四邊的距離與相鄰掛點（最小生成樹）的 ΔX / ΔY / 直線距離，3D 同步顯示尺寸線。
- **多架組裝**：「水平並排幾架／垂直堆疊幾架」把整組設計重複組裝，3D 預覽、連接件、材料表、排版與匯出一起更新。
- **連接點**：側欄以實際切割形狀的縮圖列出每種連接件、數量與用途，並列出螺栓、螺帽、木螺絲數量與長度。
- **材料表**：每種零件的縮圖、尺寸、數量，五金清單，以及每張板材的排版預覽與利用率。
- **板材計算機連動**：一鍵把 CNC 板材尺寸、張數與板厚帶到 [合板裁切計算機](https://fink1217.github.io/plywood-cut-calculator/)，算出要買幾張原板與裁切方式（計算機需包含 `claude/wood-cnc-prefill` 分支的網址帶入功能）。
- **展示名牌（選用）**：每架頂端立一片名牌，兩支榫頭插進頂板。外形可選矩形、圓角、拱形、波浪，或「沿圖案外形」（依圖案的天際線外擴後平滑，做出不規則輪廓）。匯入圖片（PNG / JPG / WebP / SVG）或直接打字，調整黑白門檻、可反轉。
- **顏料名牌（選用）**：每種顏料一片獨立的名牌板，位在層板與孔板前方、下緣對齊層板底面。兩端榫頭插進左右側板前緣的開口槽，從正面推進去、推到底定位，隨時可往前拔出；放罐子的層板與孔板完全不動。名牌高度可調（預設蓋住層板與孔板前緣、頂端略低於孔板；最高到罐頂）。名牌頂端低於孔板時不影響其他零件；高過孔板時，罐子要先提過名牌才拿得出來，罐頂距離（列距）會自動加大，只往上調。開啟時側板往前加深一個板厚＋間隙，每一列都切出插槽，日後可隨時加掛。名牌板一律跨滿兩片側板，寬度／對齊／位移調整的是文字區。每種可各自開關、各自命名（清單的色點與 3D 罐色相同）。
- **調整名牌與掛點**：點一下名牌（或顏料清單的色點）、掛點球，畫面下方出現調整面板：名牌可選靠左／置中／靠右，再用 −／＋ 或輸入數字調距離、寬度、高度；掛點可微調 X／Y。也可以直接拖控制球（橘球移動、藍球拉寬窄與高度），控制球以螢幕距離判定，觸控裝置會自動放大。拉寬窄時對齊的那一側不動（置中則兩側一起伸縮）。雙擊名牌還原滿寬置中。
- 頂端名牌與顏料名牌都有三種加工方式：
  - **雷射雕刻**：高解析度黑白點陣內嵌在 SVG 的 `engrave-raster` 圖層，ZIP 另附 PNG；側欄顯示預估 DPI。
  - **CNC 雕刻**：描成向量輪廓放在 `ENGRAVE` 圖層（DXF / SVG），CAM 以 V 刀或平刀挖槽。
  - **鏤空**：圖案外框直接貫穿切出；字中間的封閉內島（如「口」「O」）會掉出，會略過並提示，比銑刀還細的細節也會略過。
- **匯出**：DXF (R12, 圖層 `ENGRAVE` / `CUT_INSIDE` / `CUT_OUTSIDE` / `LABEL` / `SHEET`)、SVG、材料表 CSV、參數 JSON（可再匯入）。自動排版到指定板材尺寸。

## 結構與接合

| 零件 | 說明 |
|---|---|
| 側板 | 層板／孔板／頂板／背板的貫穿榫槽；上下緣有卡扣槽與連接板螺栓孔 |
| 層板、頂板 | 左右榫頭插入側板，後緣榫頭插入背板 |
| 固定孔板 | 罐孔 = 罐徑 + 餘隙，位於層板上方「固定孔板高度」處；罐子提起該高度即可取出 |
| 背板 | 離牆一個板厚（側板後緣貼牆），供螺絲頭空間；鑰匙孔掛孔 |
| **U 型卡扣**（水平延伸卡點） | 跨過相鄰模組兩片側板，卡入上下緣的卡槽 |
| **螺栓鎖點孔**（水平延伸鎖點） | 每一列在相鄰側板開對齊的貫穿孔，用螺栓＋螺帽鎖緊 |
| **垂直連接板**（垂直延伸鎖點） | 貼在上下模組側板內側（頂板與下一層底板之間的空間），每片 4 支螺栓、上下模組各 2 支，不會轉動也不會向側面脫出 |

- **公差**：所有榫槽、卡槽寬度 = 榫頭 + 公差；卡扣輪廓內縮公差。
- **狗骨頭**：依銑刀直徑在所有內角加入清角弧，讓方榫能完全插入。

## 注意

- 下緣卡扣是由下往上插入，需靠摩擦固定，建議點膠或公差設小一點；結構強度主要由螺栓鎖點與垂直連接板提供。
- 每個模組最好都有自己的牆面掛點（「自動配置」預設每模組 2 個）。
- 鑰匙孔是貫穿切割：螺絲需從牆面凸出約「板厚 × 2 + 螺絲頭厚」。
