# CNC 木頭顏料罐架產生器

在瀏覽器中參數化生成可**水平／垂直延伸**的壁掛式顏料罐木架，3D 預覽並匯出 CNC 切割檔（DXF / SVG）。

## 使用

```bash
npm start          # 開啟 http://localhost:8080
npm test           # 幾何與零件生成測試
```

（純靜態網頁，three.js 由 CDN 載入，任何靜態伺服器皆可。）

### GitHub Pages

`.github/workflows/pages.yml` 會在每次推送時先跑測試，再把網頁部署到 GitHub Pages。
第一次使用需到 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

## 功能

- **參數三層、全部連動**：
  - **基本**（6 項）：木頭厚度、組裝公差、顏料罐直徑、顏料罐高度、預計放幾種（每種一列）、每種放幾罐。
  - **加工與五金**（4 個選單）：銑刀、板材尺寸、掛牆螺絲、模組鎖點螺栓——掛孔尺寸、鎖點孔徑、排版間距等自動由此推算。
  - **進階**（預設收合、全部自動）：罐間距、罐孔餘隙、固定孔板高度、邊距、每模組欄／列數…會隨基本參數連動。輸入數值即可覆寫；若與其他參數衝突（例如孔板低於層板、模組比板材大），會自動調整並在欄位下方說明原因；清空或按「改回自動」即恢復連動。
- **自動模組化**：單一模組自動控制在約 600mm 內且一定放得進板材；罐數或種類超過時自動水平延伸／垂直堆疊。所有模組都切出延伸槽，日後可再擴充。
- **牆面掛點**：點選橘色座標球，拖拉 X/Y 軸移動（可設定吸附間距）；雙擊背板新增、Delete 刪除，也可在側欄輸入精確座標。掛點會在所在模組的背板切出鑰匙孔；若落在側板、榫槽或背板外則標紅、不切孔。
- **無邊框側欄**：總尺寸、模組資訊、容量、零件數；每個掛點到左右上下邊的距離，以及相鄰掛點（最小生成樹）的 ΔX / ΔY / 直線距離；3D 場景同步顯示尺寸線。
- **匯出**：DXF (R12, 圖層 `CUT_INSIDE` / `CUT_OUTSIDE` / `LABEL` / `SHEET`)、SVG、材料表 CSV、參數 JSON（可再匯入）。自動排版到指定板材尺寸。

## 結構與接合

| 零件 | 說明 |
|---|---|
| 側板 | 層板／孔板／頂板／背板的貫穿榫槽；上下緣有卡扣槽與鳩尾槽 |
| 層板、頂板 | 左右榫頭插入側板，後緣榫頭插入背板 |
| 固定孔板 | 罐孔 = 罐徑 + 餘隙，位於層板上方「固定孔板高度」處；罐子提起該高度即可取出 |
| 背板 | 離牆一個板厚（側板後緣貼牆），供螺絲頭空間；鑰匙孔掛孔 |
| **U 型卡扣**（水平延伸卡點） | 跨過相鄰模組兩片側板，卡入上下緣的卡槽 |
| **螺栓鎖點孔**（水平延伸鎖點，可關閉） | 相鄰側板對齊的貫穿孔，可用螺栓＋螺帽鎖緊 |
| **雙鳩尾卡榫**（垂直延伸卡點） | 嵌入上下模組側板的鳩尾槽，防止上下分離 |

- **公差**：所有榫槽、卡槽寬度 = 榫頭 + 公差；卡扣/卡榫輪廓內縮公差。
- **狗骨頭**：依銑刀直徑在所有內角加入清角弧，讓方榫能完全插入。

## 注意

- 下緣卡扣是由下往上插入，需靠摩擦固定，建議點膠或公差設小一點。
- 每個模組最好都有自己的牆面掛點（「自動配置」預設每模組 2 個）。
- 鑰匙孔是貫穿切割：螺絲需從牆面凸出約「板厚 × 2 + 螺絲頭厚」。
