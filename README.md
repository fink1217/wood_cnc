# CNC 顏料罐木架產生器

輸入罐子尺寸和要放幾罐，網頁會畫出一座掛牆的顏料罐木架，可以左右並排、上下疊高，最後匯出 CNC 或雷射用的切割檔（DXF / SVG）。

線上版：https://fink1217.github.io/wood_cnc/

## 本機執行

```bash
npm start   # http://localhost:8080
npm test
```

純靜態網頁，three.js 從 CDN 載入，隨便一個靜態伺服器都能跑。

每次 push 會先跑測試再部署到 GitHub Pages（`.github/workflows/pages.yml`）。第一次用要到 Settings → Pages，把 Source 改成 GitHub Actions。

## 怎麼用

一開始只要填六個數字：板厚、公差、罐子直徑、罐子高度、幾種顏料、每種幾罐。其他尺寸會自己算，改了任何一個數字，相關的尺寸會跟著變。

有兩個值可以自己調，空著就用自動值：

- 罐子左右的手指空間，預設 20mm，罐子之間和罐子到側板都留這麼寬。調大只會變寬，不會變深；小於 14mm 會提醒。在 3D 點一下任何一罐，也能直接調。
- 罐頂到上層的距離。最小值是孔板高度再加 8mm，再低罐子就提不出來，所以只能往上加。

加工方式、銑刀、板材、螺絲、螺栓用選單挑。「進階」裡還有十幾個值，平常不用管；想改就填數字，跟其他尺寸衝突時會自動修正，並在欄位下面寫原因。清空就回到自動。

單一模組會控制在 600mm 左右，而且一定放得進板材。罐子太多就自動拆成好幾個模組，用卡扣、螺栓和連接板接起來。模組沒有自己的頂板，上下接縫處一樣是完整的罐位，最上面另外蓋一個頂蓋。

## 掛點

背板上的圓球是掛牆的位置，會切成鑰匙孔。滑鼠可以直接拖，雙擊背板加一個，Delete 刪掉。手機上要先點一下再拖。掛點落在側板、榫槽上或背板外面會變紅，那裡不會開孔。每個模組最好都有自己的掛點，「每模組 2 個」會自動排好。

## 名牌

兩種，都可以不要：

- 頂端名牌：立在頂蓋上。外形有矩形、圓角、拱形、波浪，或沿著圖案輪廓切。可以打字，也可以匯入圖片。
- 顏料名牌：每種顏料一片，從正面插進側板的槽，隨時拔得起來，不會動到放罐子的板子。名牌比孔板高的時候，上層會自動加高，罐子才拿得出來。

在 3D 點一下名牌，就能拖球或用下面的面板調左右、寬度和高度。顏料名牌是一起調的。

圖案有三種做法：雷射雕刻（點陣圖放在 SVG，另附 PNG）、CNC 雕刻（輪廓放在 `ENGRAVE` 圖層），或直接鏤空。鏤空時「口」「O」這種字中間會掉出來，比刀還細的地方也切不出來，這些會跳過並提醒。

## 雷射切割

「加工機器」選雷射，整座都改用雷射切：

- 不加狗骨頭，板材換成雷射機台的尺寸（1300×900、900×600、600×400），零件間距 3mm。
- 匯出時會補切縫，預設 0.15mm，可以在進階裡改。
- SVG 用髮絲線，黑色是雕刻、藍色是內孔、紅色是外框，在 LightBurn 這類軟體裡設成先內後外就好。檔案裡沒有板材框和文字。
- 板子超過 10mm 會提醒，一般 CO₂ 雷射切不太穿。

## 匯出

「輸出」分頁可以打包成 ZIP，也能單獨下載 DXF（R12，圖層 `ENGRAVE` / `CUT_INSIDE` / `CUT_OUTSIDE` / `LABEL` / `SHEET`）、SVG、材料表 CSV 和參數 JSON。JSON 可以再匯入回來繼續改。

同一頁有材料表、五金數量、每張板材的排版圖，還有一個連結把板材尺寸和張數帶到[合板裁切計算機](https://fink1217.github.io/plywood-cut-calculator/)，算要買幾張原板。計算機那邊要有 `claude/wood-cnc-prefill` 分支的功能才會自動帶入。

## 結構

| 零件 | 做什麼用 |
|---|---|
| 側板 | 層板、孔板、頂板、背板都插在這裡；上下緣有卡扣槽和連接板的螺栓孔 |
| 層板、頂板 | 左右插進側板，後面插進背板 |
| 孔板 | 罐子插在孔裡，孔比罐子大一點；把罐子提過孔板就拿得出來 |
| 背板 | 離牆一個板厚，留給螺絲頭；掛點的鑰匙孔開在這裡 |
| U 型卡扣 | 左右相鄰的模組，卡在兩片側板上下緣 |
| 鎖點螺栓 | 左右相鄰的模組，每一列用一支螺栓鎖住兩片側板 |
| 連接板 | 上下相鄰的模組，貼在側板內側，上下各鎖 2 支螺栓 |

所有槽都比榫頭寬一個公差，卡扣也內縮一個公差。用 CNC 時，內角會依銑刀大小加狗骨頭，方榫才插得到底。

## 要注意的地方

- 下緣的卡扣是由下往上插，只靠摩擦卡住，建議點膠或把公差設小一點。真正受力的是螺栓和連接板。
- 鑰匙孔是切穿的，螺絲要從牆面凸出大約兩個板厚再加螺絲頭的厚度。
